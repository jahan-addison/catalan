# Euler's identity

For any real $x$, Euler's formula connects the exponential function to the trigonometric functions:

$$e^{ix} = \cos x + i \sin x$$

At $x = \pi$, where $\cos \pi = -1$ and $\sin \pi = 0$, it becomes

$$e^{i\pi} + 1 = 0$$

which links five fundamental constants, $0$, $1$, $\pi$, $e$, and $i$, using one addition, one multiplication, and one exponentiation.

## As a rotation

On the complex plane, multiplying by $e^{i\theta}$ rotates every point by the angle $\theta$, the same map as the rotation matrix

$$R(\theta) = \begin{pmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{pmatrix}$$

so $e^{i\pi}$ is a half turn, which sends $1$ to $-1$.
